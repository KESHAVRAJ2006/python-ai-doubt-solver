\# 🐍 PyMentor AI — Python Learning Assistant



An AI-powered Python Question-Answering Chatbot built using \*\*Python, Flask, LangChain, and Google Gemini\*\*.



PyMentor AI helps students understand Python concepts, generate example programs, compare Python features, and get beginner-friendly explanations through a simple web interface.



\---



\## 🎯 Project Objective



The objective of this project is to build a simple AI chatbot using LangChain that accepts a user's Python-related question and generates an AI-powered answer.



The project demonstrates how an LLM can be integrated with LangChain and deployed as a real web application.



\---



\## ✨ Features



\- 🤖 AI-powered Python question answering

\- 🐍 Python learning assistant

\- 💡 Simple explanations for programming concepts

\- 💻 Python code generation

\- 🔍 Concept comparison

\- 🛠️ Python error and exception guidance

\- ⚡ Quick question suggestions

\- 📝 Markdown-formatted AI responses

\- 📋 Copy AI answers and code

\- 🌙 Dark and light themes

\- 📱 Responsive web interface

\- 🔐 Secure API key handling using environment variables

\- ⚠️ Basic error handling

\- 🌐 Deployed as a live web application
